# Programming for AI Assignment-03
This assignment covers NumPy, Pandas, data cleaning, analysis, visualizations and animation.

## How to Run

1. Open the notebook in VS Code.
2. Select a Python kernel with NumPy, Pandas and Matplotlib installed.
3. Keep the original datasets in the data folder.
4. Run all notebook cells from top to bottom.
5. The dashboard and GIF are saved in the outputs folder.

## Challenge

The most challenging part was handling invalid and missing values without modifying the original data. I also learned how broadcasting and NumPy axes work.
